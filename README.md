# CP Games

Open index.html in a browser to play. No installation, internet connection, or build step is needed. Alternatively run `python3 -m http.server 8000`.

All four games are on the homepage: Memory Cards, Picture Matching, What’s Missing?, and This is / These are. The old Others, Under the Sea, and empty English category pages were removed.

Content comes from the six supplied classroom PDFs: school supplies, daily routine, the getting-ready song vocabulary, and This is / These are. English words, French help, and a parent vocabulary guide are included. Simple symbols are visual cues; words remain visible because some supplies share similar symbols. Games use four pairs or four rounds, no timer, unlimited retries, and restart controls. Each new vocabulary game selects four random items from the chosen lesson.

French translations are added as parent support. Optional extension activities listed in the routine PDF are not included in the core vocabulary. The song vocabulary is used; no song recording is bundled.
